# Hi, I'm Phạm Thiên Long 👋

I'm a frontend developer based in Ho Chi Minh City. I build web apps with
React, Next.js, and TypeScript, with a focus on REST API integration and
interfaces for workflows like order management and delivery booking.

## What I'm working on

- **Odoo ERP** — Building order intake and delivery booking workflows for
  modern trade sales.
- **[Second Brain MCP](https://github.com/pthieenlong/second-brain-mcp)** —
  Connecting AI agents to a local knowledge base for note-taking, tagging,
  and organization.

## Selected project

**MangaReader** — My graduation project, a manga platform with chapter
purchases, reading history, and a publisher dashboard. I built it with
Next.js, NestJS, PostgreSQL, and Prisma.

## Tech I work with

React · Next.js · TypeScript · Tailwind CSS · TanStack Query · Odoo
